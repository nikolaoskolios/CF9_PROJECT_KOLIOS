
DeathStar Test Data Application

1. Γενικά

Το παρόν αποτελεί το τελικό project που υποβάλεται στα πλαίσια του προγράμματος δια βίου μάθησης CODING FACTORY, σειράς 09 του Οικονομικού Πανεπιστημίου Αθηνών απο τον μαθητή του προγράμματος Ν. Κολιό.

Πρόκειται για ένα σύστημα που συλλέγει μέσω api client, διατηρεί και διαμοιράζει, με δυνατότητες ανάλυσης δεδομένα αυτόματων τεστ που γίνονται σε διαδοχικές δοκιμαστικές εκδοχές ενός project με σκοπό το όσο συντομότερο δυνατό εντοπισμό σφαλμάτων κώδικα (Continuous Integration - Nightly Testing).

To σύστημα συμπληρώνεται απο αυτόματα τέστ του συστήματος διαμοιρασμού καθώς και δυνατότητες διαχείρισης χρηστών καθώς και κάποιες βασικές λειτουργίες προστασίας από κακόβουλες ενέργειες. 

Το Project βασίστηκε:
Backend: Στην εφαρμογή 'Project4' από τα μαθήματα της γλώσσας Python, με προσθήκες σε επίπεδο ασφάλειας και διαχείρισης ταυτόχρονων συναλαγών στην βάση δεδομένων sqlite. 
Frontend: Στην frontend εφαρμογή από το Tiangolo template με προσαρμογή στις υλοποιήσεις των προσφερόμενων API endpoints, την σχετική ροή χρήστη καθώς και το υποθετικό σενάριο.
