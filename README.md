1.  Οδηγίες εγκατάστασης και εκτέλεσης της εφαρμογής
Κάντε clone το project στο φάκελο της επιλογής σας. 

Την πρώτη φορά που θα εκτελέσετε την εφαρμογή πρέπει να ενεργοποιήσετε το virtual environment (καθώς αυτό δεν είναι μέρος του repository). Αυτό γίνεται ώς εξής. 

Πλοηγηθείτε στον φάκελο CF9_PROJECT_KOLIOS/BACKEND.
Σε Windows εκτελέστε:
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
Σε Linux/Mac εκτελέστε:
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

Στην συνέχεια και ενόσω βρίσκεστε ακόμα στον φάκελο BACKEND εκτελέστε τα script που ξεκινούν το backend της εφαρμογής:
Για την εκκίνηση του backend σε Windows χρησιμοποιήστε:
run_dev_server.bat 
ή 
run_prod_server.bat για χρήση σε παραγωγικό περιβάλλον
Σε Linux/Mac χρησιμοποιήστε:
run_dev_server.sh
ή 
run_prod_server.sh για χρήση σε παραγωγικό περιβάλλον

Για να δοκιμάσετε το REST API μπορείτε να φτιάξετε έναν χρήστη τύπου ‘user’ μέσω του endpoind auth -> POST: /auth/ Create User

2. Γενικές πληροφορίες

Το παρόν αποτελεί το τελικό project που υποβάλλεται στα πλαίσια του προγράμματος δια βίου μάθησης CODING FACTORY, σειράς 09 του Οικονομικού Πανεπιστημίου Αθηνών από τον μαθητή του προγράμματος Ν. Κολιό.

Πρόκειται για ένα σύστημα που συλλέγει test data μέσω api client, τα διατηρεί σε βάση δεδομένων και διαμοιράζει μέσω react frontend, με δυνατότητες ανάλυσης δεδομένα αυτόματων τεστ που γίνονται σε διαδοχικές δοκιμαστικές εκδοχές ενός project με σκοπό το όσο συντομότερο δυνατό εντοπισμό σφαλμάτων κώδικα (Continuous Integration - Nightly Testing).

To σύστημα συμπληρώνεται από unit τέστ του συστήματος διαμοιρασμού καθώς και δυνατότητες διαχείρισης χρηστών καθώς και κάποιες βασικές λειτουργίες προστασίας από κακόβουλες ενέργειες. 

Το Project βασίστηκε:
Backend: Στην εφαρμογή 'Project4' από τα μαθήματα της γλώσσας Python, με προσθήκες σε επίπεδο ασφάλειας και διαχείρισης ταυτόχρονων συναλλαγών στην βάση δεδομένων sqlite. 
Frontend: Στην frontend εφαρμογή από το Tiangolo template με προσαρμογή στις υλοποιήσεις των προσφερόμενων API endpoints, την σχετική ροή χρήστη καθώς και το υποθετικό σενάριο. 

3. Σενάριο

Οι (κακοί) μηχανικοί της Γαλαξιακής Αυτοκρατορίας εργάζονται νυχθημερόν για να υλοποιήσουν το project του Death Star, ενός υπερ-όπλου που τους επιτρέπει να καταστρέφουν τους πλανήτες που αρνούνται να τους υποταχθούν. Σε αυτή τους την προσπάθεια έχουν υλοποιήσει μία σειρά από αυτόματα τεστ που εκτελούνται στα επιμέρους συστήματα του Death Star, ενώ το project είναι σε εξέλιξη, έτσι ώστε να εντοπίζουν τα πιθανά σφάλματα το συντομότερο δυνατόν και να τα διορθώνουν.  Η εφαρμογή DeathStar Test Data Application τους επιτρέπει να συλλέγουν, αποθηκεύουν, αναλύουν και να μοιράζονται τα δεδομένα από τα αυτόματα τεστ. 


4. Λειτουργικότητα

Η εφαρμογή που αναπτύχθηκε υποστηρίζει: 
-	Είσοδο στην εφαρμογή με χρήση username/password ή εγγραφή χρήστη (σελίδα: Αρχική Log-In / Sign-Up). Όσοι εγγράφονται από την αρχική σελίδα μπορούν να είναι μόνο χρήστες τύπου user, όχι τύπου admin. Admin χρήστες μπορούν να δημιουργούν μόνο οι άλλοι χρήστες admin.  
-	Καταχώρηση αποτελεσμάτων των αυτόματων τεστ κατά την ολοκλήρωση της εκτέλεσής τους μέσω ένός api client που ο χρήστης μπορεί να κατεβάσει από το front end, μαζί με ένα api token που επιτρέπει την ασφαλή επικοινωνία του api client με το backend. Το api client είναι ένα απλό πρόγραμμα python το οποίο εκτελείται αυτόματα ως τελευταίο βήμα ενός test pipeline. 
Με χειροκίνητο τρόπο από το frontend η καταχώρηση είναι δυνατή μόνο από τον διαχειριστή όπως και η διαγραφή  / τροποποίηση των αποτελεσμάτων. Οι απλοί χρήστες μπορούν να καταχωρούν αποτελέσματα μόνο μέσω του CI / api client. 
-	Την πρόσβαση στα αποτελέσματα με: 
 - Μορφή γενικής τάσης / γράφημα γραμμών μέσων όρων (σελίδα: Dashboard - Data Overview).
- Αποτελέσματα σε λεπτομέρεια, όλες οι επιμέρους κολώνες σε paginated μορφή (σελίδα: Test Results in Detail)
- Σύγκριση δύο η περισσότερων επιμέρους αποτελεσμάτων με πίνακα και γράφημα (σελίδα: Compare Test Runs)
- Ερωτήματα σε δεδομένα (σελίδα: Query Test Data)
-	Επιπλέον παρέχεται η ακόλουθη λειτουργικότητα
- Κατέβασμα λογισμικού python api client και σχετικού api token(σελίδα: Software)
- Διαχείριση λογαριασμού, πληροφορίες λογαριασμού, αλλαγή email, αλλαγή password. (σελίδα: Account)
- Λειτουργίες διαχείρισης (μόνο για χρήστες τύπου admin, σελίδα: Admin) που περιλαμβάνουν την δημιουργία / διαγραφή χρηστών τύπου user και τύπου admin καθώς και την ενημέρωση, την εισαγωγή και την διαγραφή δεδομένων test.
