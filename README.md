
DeathStar Test Data Application


1.  Οδηγίες εγκατάστασης και εκτέλεσης της εφαρμογής
Κάντε clone το project στο φάκελο της επιλογής σας. 

1.A Εκκίνηση του BACKEND
Πλοηγηθείτε στον φάκελο CF9_PROJECT_KOLIOS/BACKEND.

Την πρώτη φορά που θα εκτελέσετε την εφαρμογή πρέπει να ενεργοποιήσετε το virtual environment (καθώς αυτό δεν είναι μέρος του repository). Αυτό γίνεται ώς εξής. 

Σε Windows εκτελέστε:
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt

Σε Linux/Mac εκτελέστε:
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

Στην συνέχεια και ενόσω βρίσκεστε ακόμα στον φάκελο BACKEND εκτελέστε τα script που ξεκινούν το backend της εφαρμογής:
Για την εκκίνηση του backend σε Windows χρησιμοποιήστε:
run_dev_server.bat 
ή 
run_prod_server.bat για χρήση σε παραγωγικό περιβάλλον

Σε Linux/Mac χρησιμοποιήστε:
run_dev_server.sh
ή 
run_prod_server.sh για χρήση σε παραγωγικό περιβάλλον

Τώρα ανοίξτε έναν browser και πλοηγηθείτε στην σελίδα http://localhost:8000/docs#/
Εκεί μπορείτε να έχετε πρόσβαση στην τεκμηρίωση του REST API με Swagger. 
Για να δοκιμάσετε το REST API μπορείτε να φτιάξετε έναν χρήστη τύπου ‘user’ μέσω του endpoind auth -> POST: /auth/ Create User 
Ακόμη μπορείτε να χρησιμοποιήσετε τους προ-υπάρχοντες χρήστες 
τύπου user:
username: luke
password: testpassword
τύπου admin:
username: vader
password: testpassword

1.A Εκκίνηση του FRONTEND
Για να εκτελέσετε το frontend της εφαρμογής πλοηγηθείτε στον φάκελο CF9_PROJECT_KOLIOS/FRONTEND.
Την πρώτη φορά που θα εκτελέσετε την εφαρμογή πρέπει να κατεβάσετε τις απαιτούμενες βιβλιοθήκες της javascript/typescript με την εντολή npm install. 

Στην συνέχεια και χωρίς να φύγετε από τον φάκελο FRONTEND εκτελέστε τα script που ξεκινούν το frontend της εφαρμογής:
Για την εκκίνηση του frontend σε Windows χρησιμοποιήστε:
run_dev_server.bat 
ή 
run_prod_server.bat για χρήση σε παραγωγικό περιβάλλον
Σε Linux/Mac χρησιμοποιήστε:
run_dev_server.sh
ή 
run_prod_server.sh για χρήση σε παραγωγικό περιβάλλον

Ανοίξτε ένα νέο tab του browser και πλοηγηθείτε  στην σελίδα: http://localhost:5173/login
Εκεί θα δείτε την σελίδα σύνδεσης στην εφαρμογή
Μπορείτε να εισέλθετε στην εφαρμογή χρησιμοποιώντας έναν από τους προ-υπάρχοντες χρήστες: 

τύπου admin:
username: vader
password: testpassword

τύπου user:
username: luke
password: testpassword

Ακόμα μπορείτε να δημιουργήσετε  έναν χρήστη τύπου user ακολουθώντας το σύνδεσμο ‘Don't Have An Account? Click here to join the Imperial Engineering Corps’

Συνίσταται να χρησιμοποιήσετε έναν χρήστη τύπου admin προκειμένου να έχετε πρόσβαση στην επιπλέον λειτουργικότητα που υπάρχει για τους χρήστες αυτού του τύπου. 

Για την λειτουργικότητα ανά σελίδα δείτε την ενότητα 4. 

Για να χρησιμοποιήσετε τον api-client πλοηγηθείτε στην σελίδα ‘Software’ και πατήστε τα κουμπιά ‘Download Upload Toolkit (.zip)’ και ‘Generate API Token’. 

Αποσυμπιέστε το αρχείο upload_test_data.zip σε έναν φάκελο της επιλογής σας. Στην συνέχεια τοποθετήστε το api_token.json στον ίδιο φάκελο. Μέσα στον φάκελο υπάρχει ένα json αρχείο με πεδία αλλά χωρίς τιμές το test_result.json. Επίσης υπάρχει και ένα αρχείο με τιμές που μπορείτε να χρησιμοποιήσετε ώς παράδειγμα, το sample_test_result.json. Στο test_result.json θα συμπληρώσετε αυτόματα ή προγραμματιστικά την νέα εγγραφή από test data που θέλετε να  ανεβάσετε στο backend. Όταν γεμίσετε το αρχείο με τις τιμές που θέλετε να ανεβάσετε τότε μπορείτε να εκτελέσετε το python αρχείο upload_test_data.py. Προκειμένου να εκτελέσετε αυτό το πρόγραμμα εκτός του φάκελου του project πχ σε έναν server που εκτελούνται αυτόματα τεστ πρέπει να εγκαταστήσετε την βιβλιοθήκη της python httpx με τις ακόλουθες εντολές: pip install httpx. 

Τα Unit Tests καλύπτουν μόνο το Backend της εφαρμογής. Για να τρέξει κάποιος πρέπει να πλοηγηθεί στον φάκελο BACKEND, αφότου έχει γίνει η αρχικοποίηση του virtual environment. Εκεί πρέπει να εκτελέσει τις ακόλουθες εντολές:
Windows: .venv\Scripts\python.exe -m pytest DeathStarTestDataApp/test/
Linux/Mac: .venv/bin/python -m pytest DeathStarTestDataApp/test/


2. Γενικές πληροφορίες
Το παρόν αποτελεί το τελικό project που υποβάλλεται στα πλαίσια του προγράμματος δια βίου μάθησης CODING FACTORY, σειράς 09 του Οικονομικού Πανεπιστημίου Αθηνών από τον μαθητή του προγράμματος Ν. Κολιό.

Πρόκειται για ένα σύστημα που συλλέγει test data μέσω api client, τα διατηρεί σε βάση δεδομένων και διαμοιράζει μέσω react frontend, με δυνατότητες ανάλυσης δεδομένα αυτόματων τεστ που γίνονται σε διαδοχικές δοκιμαστικές εκδοχές ενός project με σκοπό το όσο συντομότερο δυνατό εντοπισμό σφαλμάτων κώδικα (Continuous Integration - Nightly Testing).

To σύστημα συμπληρώνεται από unit τέστ του συστήματος διαμοιρασμού καθώς και δυνατότητες διαχείρισης χρηστών καθώς και κάποιες βασικές λειτουργίες προστασίας από κακόβουλες ενέργειες. 

Περιγραφή της εφαρμογής:
Το Backend βασίστηκε στην εφαρμογή 'Project4' από τα μαθήματα της γλώσσας Python, με προσθήκες σε επίπεδο ασφάλειας και διαχείρισης ταυτόχρονων συναλλαγών στην βάση δεδομένων sqlite. 
Πρόκειται για μία εφαρμογή σε Python 3 και FastAPI, που χρησιμοποιεί SQLAlchemy για το αντικειμενο-σχεσιακό μοντέλο (ORM) με βάση δεδομένων SQLite και Alembic για την διαχείριση των αλλαγών στο σχήμα της βάσης δεδομένων. Χειρίζεται την αυθεντικοποίηση με JWT και κλειδιά API, και για ασφάλεια χρησιμοποιεί bcrypt κρυπτογράφηση κωδικών και περιορισμό πρόσβασης από την ίδια διεύθυνση IP με slowapi. 

Το Frontend βασίστηκε στην frontend εφαρμογή από το Tiangolo template με προσαρμογή στις υλοποιήσεις των προσφερόμενων API endpoints, την σχετική ροή χρήστη καθώς και το υποθετικό σενάριο. 
Πρόκειται για μια εφαρμογή σε React και TypeScript, χτισμένη με το Vite, η οποία χρησιμοποιεί το TanStack Router και το TanStack Query για την πλοήγηση (routing) και την ανάκτηση δεδομένων (data fetching), καθώς και το Tailwind CSS για styling. Χρησιμοποιεί τα React Hook Form και Zod για την επικύρωση φορμών (form validation) και το Recharts για τα γραφήματα.

4. Λειτουργικότητα του frontend
Η εφαρμογή που αναπτύχθηκε υποστηρίζει: 
- Είσοδο στην εφαρμογή με χρήση username/password ή εγγραφή χρήστη (σελίδα: Αρχική Log-In / Sign-Up). Όσοι εγγράφονται από την αρχική σελίδα μπορούν να είναι μόνο χρήστες τύπου user, όχι τύπου admin. Admin χρήστες μπορούν να δημιουργούν μόνο οι άλλοι χρήστες τύπου admin.  
- Καταχώρηση αποτελεσμάτων των αυτόματων τεστ κατά την ολοκλήρωση της εκτέλεσής τους μέσω ένός api client που ο χρήστης μπορεί να κατεβάσει από το front end, μαζί με ένα api token που επιτρέπει την ασφαλή επικοινωνία του api client με το backend. Το api client είναι ένα απλό πρόγραμμα python το οποίο εκτελείται αυτόματα ως τελευταίο βήμα ενός test pipeline. 
Με χειροκίνητο τρόπο από το frontend η καταχώρηση είναι δυνατή μόνο από τον διαχειριστή όπως και η διαγραφή  / τροποποίηση των αποτελεσμάτων. Οι απλοί χρήστες μπορούν να καταχωρούν αποτελέσματα μόνο μέσω του CI / api client. 
- Την πρόσβαση στα αποτελέσματα με: 
    - Μορφή γενικής τάσης / γράφημα γραμμών μέσων όρων (σελίδα: Dashboard - Data Overview).
    - Αποτελέσματα σε λεπτομέρεια, όλες οι επιμέρους κολώνες σε paginated μορφή (σελίδα: Test Results in Detail)
    - Σύγκριση δύο η περισσότερων επιμέρους αποτελεσμάτων με πίνακα και γράφημα (σελίδα: Compare Test Runs)
    - Ερωτήματα σε δεδομένα (σελίδα: Query Test Data)
    - Επιπλέον παρέχεται η ακόλουθη λειτουργικότητα
    - Κατέβασμα λογισμικού python api-client και σχετικού api-token (σελίδα: Software)
    - Διαχείριση λογαριασμού, πληροφορίες λογαριασμού, αλλαγή email, αλλαγή password. (σελίδα: Account)
    - Λειτουργίες διαχείρισης (μόνο για χρήστες τύπου admin, σελίδα: Admin) που περιλαμβάνουν την δημιουργία / διαγραφή χρηστών τύπου user και τύπου admin καθώς και την ενημέρωση, την εισαγωγή και την διαγραφή δεδομένων test. 


5. Σημειώσεις
 - Το .env αρχείο που βρίσκεται στο root φάκελο της εφαρμογής κανονικά θα συμπεριλαμβάνεται στο αρχείο .gitignore για να μην βρίσκεται στο github repository καθώς περιέχει πληροφορίες που μπορούν να θέσουν την ασφάλεια της εφαρμογής σε κίνδυνο. Ωστόσο στο πλαίσιο της εργασίας το εν λόγω αρχείο ανέβηκε στο repository προκειμένου να κάνει την χρήση της εφαρμογής ευκολότερη από τους δασκάλους και συμφοιτητές του προγράμματος CF9. 
 - Η βάση δεδομένων sqlite που χρησιμοποιήθηκε εδώ δεν ενδείκνυται για παραγωγικές εφαρμογές, ωστόσο η επιλογή της έγινε και εδώ για λόγους ευκολίας χρήσης της εφαρμογής από τους δασκάλους και συμφοιτητές του προγράμματος CF9. 
 - Η εφαρμογή δεν έχει δοκιμαστεί πλήρως σε παραγωγικό περιβάλλον
 - Η εφαρμογή έχει δοκιμαστεί σε linux και windows, όχι mac.
